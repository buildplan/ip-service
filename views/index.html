Frequently Asked Questions

Is this service free?

Yes, this is a free tool for the community. Please respect the fair usage policy to keep it available for everyone.

How do I use this in scripts?

Use curl ip.wiredalter.com for a plain text IP or append /json for detailed metadata.

Does this detect VPNs?

Yes. We use the IP2Location LITE database specifically for proxy detection, combined with a manual analysis of ASN providers to catch unlisted datacenters.

Data Privacy

No logs are kept. This service runs entirely in memory to ensure privacy and security.

Are there Rate Limits?

To ensure stability, we limit requests to 100 per 5 minutes per IP address. Exceeding this will result in a 429 HTTP error.

How accurate is the data?

We combine MaxMind GeoLite2 for location/ISP data with IP2Location for threat intelligence. Both databases are updated regularly.

Fully Open Source

For full transparency, this service runs entirely in memory and logs nothing. Inspect the code, audit the security, or host it yourself.
